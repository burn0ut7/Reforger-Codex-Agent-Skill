# Reforger Gauntlet

Treat the invocation text as `GOAL`. If it is empty, ask for one sentence.

1. Create a goal for `GOAL`, read the workspace instructions, and apply `$reforger`. Turn the request into evidence-backed acceptance checks.
2. Split independent work into non-overlapping cards and dispatch Luna subagents at high reasoning in parallel. Keep shared integration work with the coordinator.
3. Have each worker implement and verify its card. Give its raw artifacts to a separate harsh Luna High critic at high reasoning. Accept only proven checks; return each rejection and exact evidence gap to the worker. Visual verdicts require real Workbench captures and cite visible differences.
4. Integrate the accepted work and satisfy every repository-required verification, documentation, Workbench, commit, and push gate. Complete the goal only when the integrated result is accepted.
